# 难度与波次强度

> 实现：`src/galaxy/01_difficulty.galaxy`，消费方 `50_waves.galaxy` 和 `12_energy.galaxy`。

## 它替换掉了什么

基线 §2 原本写的是波次"按该玩家自身的**发展程度**单独缩放"。**这条改掉了。**

发展程度不是一个真实的量——得从设备数和升级数里拼一个加权和出来。更糟的是它意味着**你打得越好游戏越难**，那是把跑步机装扮成曲线。

## 四档，逐玩家

**Casual / Normal / Hard / Brutal**，沿用暴雪战役那套名字，每名玩家各选各的。

理由不只是"更容易实现"：

- **是选的不是量的**，所以没有人因为玩得好而被惩罚。
- **逐玩家**，所以新人可以在一桌老手里选 Casual 照样学得下去。这和 §4.4 的图鉴准入是同一个形状：难度是每个人实际能承受的东西的函数，而且**不需要当众告诉谁"你是全队被拖慢的原因"**。
- **可以说出口**。"我开的 Hard"是一句话，"我的发展系数是 1.4"不是。

新人开 Casual 也**不会**变成邻居的负担：他那片扇区刷得少，漏出去的自然也少——基线唯一允许的那条负面传导变小了，不是变大。

## 全局难度 = 全桌的平均

个人难度决定个人波。但有两样东西是共享的、因此读不了个人数字：**能源目标**，以及**考验的上限**。

**取平均不取最大。**基线 §2 已经为全船大潮吵完了这一架——"按全队总量缩放，而非按最强玩家缩放"——理由原封不动搬过来：取最大意味着**一名玩家开 Brutal 就能把全桌拖进午夜考验**，那是一个人的选择伸进了别人的游戏。取平均则每个人只按自己那一份挪动共享数字。

**四舍五入到最近而不是向下取整。**三个 Brutal 加一个 Casual 是 2.25，落在 Hard；向下取整会把这桌叫成 Normal 并把考验封在正午——那是一个人的选择替另外三个人做了决定，和取最大是同一个反对意见换个方向。

## 考验上限

四档难度**一对一**映射四档考验。这不是个待整理的巧合，它就是那个映射：

| 难度 | 考验上限 |
|---|---|
| Casual | 黎明 Dawn |
| Normal | 正午 Noon |
| Hard | 黄昏 Dusk |
| Brutal | 午夜 Midnight |

**考验本身没做，但上限做了**——上限是关于**难度**的事实，不是关于考验的事实，所以它不需要任何还不存在的东西。

考验落地时读 `Diff_OrdealCap` 和 `Diff_Of`。**别再长出第二份刻度。**

## 能源目标按平均难度缩放

`Diff_GoalFrom`。Casual 70% / Normal 100% / Hard 125% / Brutal 155%，全是 TUNING，而且**故意比波次那条（60/100/145/200）更平**：更难的局该更长也更忙，但两样同时翻倍就是相乘了。

这一步是让个人难度对得起共享目标的关键。没有它，全桌开 Casual 就是用变弱的对手去打一个没变的目标——**那是折扣，不是更小的游戏**。有了它，Casual 真的更短、Brutal 真的更长，这才是这个词该有的意思。

正式局里目标只在 init 算一次——难度来自大厅，之后不会动，而 §8.4 那条"大厅在 init 读完、之后不要再依赖它"指向同一个做法。但公式本身放在 `Energy_Retarget()` 里而不是写死在 init 中，因为 `-diff` 会当场改难度：**一个改了设置却让派生值停在旧数上的调试命令，测的是一个正式局里不可能出现的状态。**

## 通道

**逐玩家的 lobby Game Attribute**（`GameAttributePlayerValue`），也就是 §7.8 给核心抑制挑的同一个通道——它字面上就是"每个槽位一个下拉框"。

`PlayerDifficulty()` **不是**这个东西，它是 AI 槽位难度，对人类玩家没意义。

属性还没在编辑器里建。读到空串就回落 Normal，所以**代码现在就能跑，建好之后自动生效、不用改一行代码**。值匹配只看首字母，所以值 id 叫 `Casual` 还是 `Easy` 都认。

## 还是占位的

`50_waves.galaxy` 的逐波递增（`c_waveBaseSize + gv_waveNumber`）仍然是占位。基线把强度曲线推迟到它要平衡的机制存在之后，而**难度是乘在那条曲线上的，不是替代它**。

## 调试

`-diff` 打全桌的设置（不只是你的——"设置不一样"正是这功能的重点），第一行是全局：

```
table = Hard  ordeal cap Dusk  energy 0/250
```

`-diff casual|normal|hard|brutal` 设自己的，**当场生效**。
