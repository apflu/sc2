# 融毁

> 实现：`src/galaxy/13_meltdown.galaxy`。

## 一轮

```
点名 → 60 秒内必须有工作「开始」 → 否则 Qliphoth 归零，全局能源扣一成
```

融毁是这个游戏的节拍器。收容单元和工作本身**没有任何理由在某个特定时刻发生**——一桌人只要不按工作键就永远不会有危险。融毁是让原地不动开始有代价的那个东西。

## 五个不是从"融毁"这个词里推出来的决定

**看开始，不看完成。**融毁问的是"派谁去哪一个"，而这个决定在员工迈步的那一刻就已经做完了。看完成的话，第 55 秒派出去的人就是白跑一趟。工作做砸了已经在扣员工 SP，融毁不该再罚一次。

**归零而不是递减。**融毁是把计数器一次花掉，不是慢慢磨。所以无视一次融毁是一个**决定**，不是一处漏水。计数器归零之后各自做什么仍然没定——那是逐异想体的作者内容，不是规则。

**被点名时已经有人在里面工作的，倒计时不启动**（`HELD`），一直等到那次工作结束——完成、大门被打掉、员工阵亡或陷入疯狂，四条出口一视同仁。

> 这不是宽容，是同一条规则读仔细了：既然回应方式是"开始一次工作"，而里面的人没法再开始一次，那 60 秒里就有一大段时间**正确操作根本按不出来**。挂起之后，窗口才真的是窗口。
>
> 注意它**不**做的事：在飞的那次工作**不算回应**，因为它开始时还没有任何东西需要回应。它结束之后钟才走，人还是得派。

**等级全局，点名逐玩家。**共享的是**节拍**不是惩罚。邻居无视自己的融毁，突破的是他自己的异想体，到你这里的是一场架——基线唯一允许的负面传导。你的收入、属性、成功率不因他动一分。

**能源是唯一的共同代价，而且它合法。**能源是块没人能从里面花钱的记分板，扣它只是把全队推离终点，不改变任何人抵达终点的速率。共享胜利条件允许，共享钱包不允许，这一刀正好切在两者之间。

## 归属是空间性的

先看控制面板的所有者，再退到 `Sector_OwnerNear`（最近的核心）。

**没有面板也没有核心的收容单元属于 0 号，永远不会被点名。**`-melt` 会把它打成 `owner=NOBODY`——因为一个悄悄不被点名的单元和一个坏掉的融毁看起来一模一样。

## 数的是格子不是轮次

`Melt_AnsweredBy` / `Melt_MissedBy` 数**格子**。

控制部任务 3「妥善处理3轮融毁」读的是**轮次**，但一个被挂起的格子可以横跨好几轮，"它属于哪一轮"是个有真答案但没有便宜答案的问题。留给任务系统（清单第 7 项）去定，现在数格子，免得一个凑合的轮次口径被当成正式的。

## 待定

- 计数器归零之后各个异想体分别做什么（逐异想体作者内容，和 `13_containment.galaxy` 里那个洞是同一个）
- 哪些异想体是"工具"因此永不被点名（培训兔兔 "不计入融毁计数"）。`Melt_CanBeNamed` 是那个钩子，per-type 标志的通道还没定
- 等级除了"点名更多格子"之外做什么。培训部核心抑制让属性随它下降、福利部弹药随它回满，两者都属于还不存在的系统。`Melt_Level` 是读口

## 附带

`Work_Tick_Func` 原来只在**员工死亡**和**异想体出逃**时中断工作。现在**疯狂**和**大门被打掉**也中断了——前者是因为一次糟糕的工作足以把做它的人打崩，而一个已经不运转的人不该还在工作。这条循环之前是断的。
