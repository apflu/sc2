# 员工、异想体与跨局持久化

> 状态：由设计对话整理。**MVP 之后**的一层，但其中若干条会反过来约束现在的实现（见"对当前实现的约束"）。
> 约定沿用基线：**[已定]** 已拍板；**[提案]** 推导结论，实现前需确认；**[开放]** 明确不下结论。
> **异想体的实际机制改动本文一律不下结论**，只登记问题。

---

## 0. 一个时间尺度的错配，先纠掉 **[已定]**

原作的"幕间成长"发生在**一周目之内**——50 天是一次连续的游戏。

在本作里，**一局就是一周目**，波次就是天数。所以"幕间成长"的对应物是**波次之间**，不是**局与局之间**。

推论：**"一局打不完整个升级链"是局内节奏问题，不能用存档去解。**存档解决的是跨局的内容解锁，是另一件事；用它来补局内节奏，两边都会变形。

---

## 1. 升级树打不完是特性 **[已定]**

3 异想体 + 1 工具异想体的编制下，单个玩家一局买不满自己部门的升级树。这不修。

**把它从"肝的问题"变成"选择题"**：树上有 N 个，你买得起 N/2，买哪一半。这是唯一能让重玩有意义的形态——如果一局能打满，第二局就没有理由不重复第一局。

更重要的是**这棵树本来就不是个人级对象，是团队级对象**，这一点设计里已经写死了：

- 基线 7.1 要求一局至少 3 个不同部门
- 中央本部的"权威"升级，字面意思就是把这局没人选的部门的 lv1 补上

一局里树是被**队伍**打完的，不是被玩家打完的。中央本部这个部门的存在本身就是这条规则的人格化。

## 2. 员工（NPC agent）**[提案]**

### 2.1 要它的理由不是"养成"，是异想体没有动词

目前结构里，一个异想体是"建起来、它产出、偶尔越狱"——那是个有剧情的矿点。

原作里异想体的动词是"**派谁去，做哪种工作**"：属性匹配决定成功率，失败掉 SP，SP 崩了出事。**没有一个具名的人可以派，这个动词就不存在**，异想体只能退化成设备。

所以"部门升级只是系统解锁、几乎和异想体没有交互"这个症状，缺的是**交互的载体**，不是交互的内容。

基线 5.1 写的"MVP 中 NPC 完全无法交互"、10 里的"NPC 交互"placeholder，就是这一层留的位置。

### 2.2 成长轴：不是买来的，是工作换来的

原作有两条，**两条都不花钱**：

| 轴 | 来源 | 货币性质 |
|---|---|---|
| 员工属性（勇气/谨慎/自律/正义） | 工作本身 | 局内、私有 |
| E.G.O（武器/装甲/饰品） | 从异想体掉落 | 局内、私有 |

于是：**矿石买系统解锁（部门升级），工作换人的性能（属性 + E.G.O）。**两条轴不同货币、不同来源，天然不打架。

副作用是部门升级终于有了非全局数值的作用对象——"你的 agent 做压抑工作时成功率 +X" 和"所有盟友移速 +0.05"完全不是一个设计密度。

### 2.3 引擎表达：四条独立的 veterancy

四项属性 = 四个 `CBehaviorVeterancy`，挂在同一个 agent 单位上。XP 的原生接口按 behavior 名字寻址：

```galaxy
native void UnitXPAddXP           (unit inUnit, string inVeterancyBehavior, fixed inXP);
native int  UnitXPGetCurrentLevel (unit inUnit, string inVeterancyBehavior);
```

一个单位可以同时挂四条独立经验曲线，每条自带等级、自带每级的 `Modification`、自带 UI。工作结算就是一句 `UnitXPAddXP`，升级效果不需要脚本。

和电力用补给、失能用换单位类型、危险等级用 attribute 是同一个路子：找到引擎里已经存在的那个东西，然后把脚本删掉。

### 2.4 属性上限要求要**刻意保留**

原作里有一批异想体要求员工的某项属性**不能高于**特定值（O-05-30、F-05-32、T-01-68、F-01-87、O-02-98 等）。

这不是需要抹平的怪癖，是"练满即最优"的解药。有了它：

- 满级员工**不是万能的**
- 你需要的是**有层次的班底**，几个练满的，几个刻意留着低正义的
- 员工系统从升级跑步机变成班底管理

这也是永久死亡这个惩罚配得上的前提：死一个人的痛感取决于**死的是哪一个**，而不是掉了多少经验。

推论——**培训部（Hod）的职能因此具体化**：不该只是"练得更快"，而该是"**练得更可控**"，定向加某一项、或者把某项**降**回去。后者原作没有，但在必须容纳新人的合作框架里，它把一次误练从"这个员工废了"降级成"花点时间修"。

**员工等级取"属性等级之和"，不取"最低项"——这一条请刻意保住。**

按 `docs/usr/quests_unlocks.md` 的表，等级 V 要求和 ≥16，而 `V+V+V+I = 5+5+5+1 = 16`：**一个三项 85+、一项低于 30 的员工仍然是 5 级**。

这正是上面那批"某属性不能高于 X"的异想体的活路。培训部的挑战任务要求"员工全部为 5 级"——如果等级取最低项，做完这个挑战的玩家就再也没有员工能去工作那批异想体了，一个部门的终点奖励会顺手关掉一整类内容。用和则不冲突，而且还保留了"练哪三项"的构筑选择。

哪天有人觉得"和"不直观想改成"最低项"，这就是不能改的理由。

### 2.5 编制与操作负担

6 个玩家、实时、有波次压力，每人还要管员工 + 英雄 + SCV。

- **每人 3-5 个具名 agent**，对上 3+1 异想体
- 指派是**常驻指令**（这个人负责这个异想体，自己循环工作），不是每次工作点一下

否则波次一来所有人都在管人，没人在防守。

### 2.6 死亡惩罚已经有承重点了，别削

中央本部的整个身份就是补充与复活：被动是 npc 更多且持续补充，"兜底" lv1 是重建被摧毁的部门。**agent 死了如果很便宜，这个部门就没有身份了。**

基线 8 的"目睹 NPC 死亡"作为 SP 损失来源，也依赖 agent 是有身份的个体。

### 2.7 成长不得唯一依赖异想体抽取

如果练属性只能靠工作合适等级的异想体，那抽取池就变成了进度系统的承重墙，差一点的抽取会变成死局。

必须有一条**不依赖抽取的、更慢的**成长路径（培训部、工具异想体、或在职时间）。坏抽取应该只意味着"这局慢"，不能是"这局废"。

## 3. 异想体的两个坐标 **[提案]**

危险等级不是一条单调难度轴。把它当单调轴用，就会得到和熟练玩家直觉相反的系统。

### 3.1 两个必须分开的坐标

| 坐标 | 管什么 | 单调吗 |
|---|---|---|
| **突破后果** | 越狱之后的血量、伤害、防守成本、E.G.O 品级 | **单调**：Zayin < Teth < HE < WAW < Aleph |
| **残余管理难度** | 知道一切之后还剩多少麻烦 | **不单调** |

### 3.2 为什么不单调——观察数据

- **Teth 与 HE 之间是质变，不是量变**。Teth 几乎只有对**一名**员工造成损失的能力，且**损害无法扩散**（潜在杀伤最高的 F-01-02 也只是缓慢走向主休息室做一次性爆炸；O-04-84 在地面伪装、对路过者造成巨量伤害，但它不移动）。HE 具有相当的扩散能力。
- **许多熟练玩家宁愿拿 WAW 也不愿意拿 HE**。HE 一批机制是强制损耗：O-01-15 管理不善时持续 AoE，除非献祭一名员工；上面那批"属性不能高于 X"的要求。
- **WAW 管理得当时（除 T-04-53 等少量特例）可以做到完全无法出逃**，前提是属性足够。
- 但 **WAW 突破而火力不足是无法制止的灾难**，HE 在数值上反而友善。

### 3.3 由此得到的公式

> **突破后果是固定的；管理难度是知识的函数。**

一个 WAW 对不认识它的人是灾难，对认识它的人接近零风险——"属性足够"本身就是"知道要哪几项属性"。知识把 WAW 的管理难度压到接近 0。

**HE 压不下去。**即使全知全能，强制损耗依然存在。它不是可以被知识规避的失误。

所以第二个字段的语义不是"难度"，是**残余**：知识扣掉之后还剩什么。

- WAW 残余 ≈ 0
- HE 残余高
- Teth 残余低**且损害无法扩散**

### 3.4 这条公式解释了准入规则

"完全解锁的 WAW 可以进第一/第二格"不是特例补丁，是公式的自然结果：**准入看的是这个玩家面对它的实际残余难度，而图鉴解锁是式子里唯一的变量。**

HE 因为残余项高，无论解不解锁都不该轻易进早期槽位——这恰好复现了熟练玩家的真实偏好，而且是系统推出来的，不是手工打的补丁。

## 4. 槽位与选取 **[提案]**

### 4.1 发牌

- **三选一**
- **各玩家的候选互不重叠**，同时选

不做共享牌池的轮流 draft：那会让一个犹豫的玩家卡住全场，而且新人被五个人等着的时候只会随便点一个。

### 4.2 准入

槽位准入读**残余管理难度**，不读危险等级。危险等级只决定这个异想体越狱之后有多贵。

早期槽位的候选来自"该玩家面对它的残余难度足够低"的集合；图鉴完全解锁把一个异想体的残余难度降到它的下限。

### 4.3 UI 就是存档的说明书

沿用原作：**已解锁（观察等级 1）显示名字，未解锁只显示编号**；无论何时都显示当前可用的说明文本。

选择界面因此同时是"跨局存档买到了什么"的读数，不用另做成就页。

### 4.4 白送的性质：难度自动跟着 lobby 的知识水平走

- 一桌全新人 → 早期槽位里根本不会出现 WAW → 这局自然温和
- 一桌老手 → 第一格就能开 WAW → 这局自然激进

**不需要难度选项**：难度是这桌人的图鉴的函数。

而且老玩家的存档兑现方式是**他自己去承担本局最危险的收容单元**，不是他数值比别人高。这正是最高原则里"让高水平玩家有机会力挽狂澜"的那根杠杆，现在有了准入条件，不再靠自觉。

新人被保护的方式是**那个选项不出现在他面前**，他没有做出一个自己无力评估的决定的机会。这和"给他一个减益"是完全不同的两件事。

## 5. 越狱不得导致软卡死 **[已定]**

有一类异想体（如 O-01-04）在特定情况下要过一个极难的检定，失败即突破。单机里这是重开；**5 人合作里这是让一个人在剩下 40 分钟当观众，而且专挑新人。**

这个不靠调数值躲，靠构造消灭——**越狱复用已经做好的"失能 → 修复"循环**（基线 4.5 的架构要求已经承诺了这一点）：

1. 突破 → 它变成战斗目标，防御层接管
2. 重新收容 / 打死 → 收容单元处于失能态
3. 修好 → 恢复运作

代价是**员工、时间、以及全场的防守压力**，全都是真代价。但**永远不是槽位的永久损失**。

## 6. 跨部门借异想体练级：允许，不削，定价 **[提案]**

玩家会想到用控制部去别人的 Zayin 上练班底，而不在自己的 WAW 上冒险。这种想法应该被奖励——它就是"高水平玩家力挽狂澜"的样子。

控制部升级说明里价已经开好了，切分切在对的地方：

| | 给不给 | 为什么 |
|---|---|---|
| 员工属性成长 | **给** | 局内、私有、局终即失。给了很安全 |
| 图鉴进度 | 不给 | 持久，会蛀空第 4 节的准入机制 |
| PE-Box / E.G.O | 不给（除非自己已完全解锁） | 持久，构成权力 |
| 矿物 | 给（不受影响） | 已定 |

再加一个不用写数字的天然代价：**员工得自己走过去。**跨区域路程 + 波次期间暴露在外，成本随地图布局自动缩放。

顺带，这让控制部有了真正的合作身份：它的价值是**让别人的员工能成长**，不是自己更强。

## 7. 任务、解锁与核心抑制 **[提案]**

具体任务内容在 `docs/usr/quests_unlocks.md`（策划侧，持续更新）。本节只写规则。

### 7.1 结构

每个部门 4 个递进任务：

| | 解锁 |
|---|---|
| 默认 | 只有第一条升级线可研发 |
| 任务 1 | 其余两条线的研发选项 |
| 任务 2 / 任务 3 | 各解锁一个升级**等级上限** |
| 任务 4 | [挑战]，通常挂在核心抑制或考验上 |

### 7.2 存档规则：+1 / 局

- 一局中完成的**第一个**任务入存档，同局完成的其余任务不入
- 局内立刻获得的是**准入**（线路、等级上限）
- **永久奖励（部门被动）从入档后的下一局起生效**

第三条要写准：不是"完成后的下一局"。同局的第 2、第 3 个任务不入档，所以它们没有"下一局"，其永久奖励要等到某一局把它作为**第一个**任务完成时才存在。现在只是措辞，实现时就是 bug。

把永久数值推迟到下一局这个决定本身是对的：**局内完成任务只给准入、不给被动数值**，于是一局之内每个人的被动强度是固定的，平衡可读性好很多。

### 7.3 最强的性质：差距有界，而且会饱和

**任意两名玩家之间的硬实力差距上界是 4 局，然后永久饱和。**不是增长得慢，是封顶——打了 400 局的人和打了 4 局的人在同一个部门上完全一样。

而且局内天花板不由存档决定：空存档玩家靠当场做任务照样能升到 lv3。所以差距连暂时的都不构成硬实力，只构成**节奏**。老手比新人多的是**选项的宽度**，不是**已经买好的东西**。

这是最高原则在这一层的结构性保证，不靠数值调。

### 7.4 两道闸门必须都咬合

- **任务**抬的是上限：哪几条线开放、最高到几级
- **矿石**决定这局实际买了哪几个

做满任务的老手面对的仍然是"我买得起 6 个，树上有 12 个"。如果任务成了唯一约束，§1 的"选哪一半"就蒸发了。

### 7.5 溢流进多样性

同一局里超出 +1 的任务，**不给下局的升级等级，但照常给图鉴进度、异想体解锁池、核心抑制进度**。

没有这条会出事：任务 N 一完成，这局剩下的时间对存档就是零，于是**早退变得理性**，短局比长局的存档效率高，直接鼓励重开刷。在 4-6 人合作生存里这是不能有的。

有了这条：权力刻度严格 +1/局（意图不变），多样性刻度永不饱和（永远有理由打完），而多样性那条线**不会让人变强，只会让桌上出现更奇怪的东西**。

### 7.6 任务内容的约束

**必须在任何合法的异想体抽取下都可完成。**要求"对一个 WAW 工作"而这局的准入规则不给 WAW，那这局的 +1 就被抽卡锁死了——这是 §5 刚消灭的软卡死搬到了元层。

**必须和"把部门玩好"同向，不能和防守抢时间。**好的任务是"把你部门本来就该做的事做到量"，做任务就是在打好这局。

**压制类任务需要时限。**惩戒部与培训部有若干"压制 N 个异想体"的任务，而压制的前提是它先突破收容——这会让这两个部门**有动机不去好好收容**。原则允许外溢，但这是第一次出现**被激励的外溢**而不是失误造成的外溢，两者体感完全不同。建议"突破后 N 秒内压制才计入"，既堵掉养着刷，又正好是惩戒部该有的手感。（具体见 §10）

### 7.7 lv4 的定价意图

lv4 是挑战奖励，**本来就不该在一局内解锁**，它属于精英核心玩家。

它靠**价格**而不是靠条款保持"不是通关条件"：lv4 贵到只有在资源丰富时才买得起，而资源丰富意味着设施里有高收益的 WAW/Aleph。所以 lv4 出现 = 这个玩家在成功运营高档异想体，**奖励顺带成了一个可读的桌面状态**。

**这里写下的是意图，不是数字。**价格执行约束的前提是价格高得离谱；以后调经济曲线的人如果只看见一个数值，很可能觉得偏高就往下调，而那个数值承载的是"这一级不该在常规局里出现"。

### 7.8 核心抑制

**独立的一局**，不属于常规游戏难度，建议预先组队的 4-6 人进行。

- 每名玩家可开关**自己部门**的挑战
- **负面效果对全桌生效**，不只对本部门

**硬前提：开关必须在 lobby 阶段决定并锁定，且全桌可见。**

原则禁止的是"他人的**失误**降低你的性能"。开启核心抑制是选择不是失误，所以合法——但前提是它真的是选择。局内可切换、或者别人看不见谁开了，它立刻变成"未经我同意的降低"，那就是原则要禁止的那件事换了个入口。lobby 阶段决定，别人才有机会说"这局别开三个"或者退出。

**这是一个公地结构，"鼓励"撑不住。**奖励私有（那名玩家的任务 4），代价全桌。自然均衡是所有人都开。两条机制兑现"不要开太多"：

1. **叠加代价超线性**——开两个明显比开一个的两倍更糟，队伍会自己刹车
2. **任务 4 目标达成后需完赛才结算**——开五个 → 全灭 → 谁都拿不到。公地问题**自我修正**，不需要设上限

第 2 条现在只有一部分任务 4 满足（培训部、安保部写了"完成一场游戏"，控制部/情报部/惩戒部没有）。建议统一。

**设计核心抑制的生成规则**：

> **把这个部门赖以生存的那件事，变成敌人。**

控制部靠"命令会被执行" → 指令被调换、NPC 自行跑到别的房间。它攻击的不是操作，是 §2.5 那个"派完就不管"的常驻指令机制所依赖的**信任**。情报部靠"我知道" → 海量正确但无用的信息把画面淹掉。

剩下部门照此推：安保部（工事挡得住 → 工事失效/治疗失效）、培训部（员工会成长 → 属性随融毁下降）、中央本部（补充与复活）、福利部（休息室能恢复）、记录部（记录可信）。

**实现形态**：这是一个**游戏模式**而不是难度滑块，自然表达是 lobby 的 Game Attribute，同一张图开局读属性分支，不另做一张图。现在唯一要守住的是**代码不要假设"只有一种模式"**——目前没有任何地方假设了，所以这条是零成本的。

### 7.9 收益 / 威胁比不变量

异想体后续会与资源挂钩（方式待议）。一旦成立，链条闭合：

```
图鉴解锁 → 高档异想体准入 → 更高收益 → 买得起更多（含 lv4）
```

这条路径本身不违反原则——收入各人各算，老手富不会让新人变穷，没有任何人的速率被别人降低。

但它给 §4.4 的自动难度缩放加了一个前提：

> **每一档异想体的"收益 / 威胁"比必须大致恒定。**

- 3 倍收益 / 1.5 倍威胁 → 老手桌白嫖，解锁变成了纯强度
- 1.5 倍收益 / 3 倍威胁 → 解锁反而是惩罚，没人愿意开新东西

只有比值守恒，老手桌才是"同一个游戏放大了一号"。**这不是平衡微调，是结构性前提**：收益和威胁必须成对设计，不能一个人调收益、另一个人调越狱强度。

## 8. 跨局持久化 **[已定]**

### 8.1 只存解锁，不存数值

模型是 **Risk of Rain 2，不是 Deep Rock / Darktide**：跨局持久化增加的是**内容的多样性**，不是**角色的强度**。

**存**：

- 图鉴 / 观察等级
- 异想体解锁池（解锁一个异想体是把它加进池子，不是给你加数值）
- 任务进度
- 核心抑制（挑战）进度
- 部门解锁、称号、纪录

**不存**：员工属性、升级等级、资源、任何进入战斗计算的数字。

### 8.2 三个理由，按重要性

1. **它和最高设计原则是同一个伤口的另一面。**持久化强度会让角色性能变成**时长的函数而不是水平的函数**——高水平新玩家会比低水平老玩家弱。原则里明确点了"包括其资源收入速率、角色性能等"。
2. **它会把玩家池劈开。**难度必须按某个存档状态调，而那个状态对所有其他人都是错的。老玩家没法和新朋友一起玩：要么碾压，要么新人是累赘。
3. **bank 是可以改的。**签名密钥在地图脚本里，能扒出来。这本身就是只存 flag 的最强论据：**改一个 flag，你解锁了本来也会解锁的内容；改一个数值，你把另外五个人的这局游戏毁了。**

### 8.3 还有一个白送的性质

**知识是可以白送的。**老玩家对着语音说一句"这玩意别做压抑工作"，新玩家立刻就有了。持久化的东西只要是知识，就永远不会卡住队友。

### 8.4 实作注意

- 存档是 SC2 bank，`BankLoad` / `BankSave`，**每个玩家一份本地文件**
- 多人局里 bank 必须在 **init 阶段**读完，之后不要再依赖它做同步决策
- 只存 flag 让这个同步面尽可能小——这是第 8.2.3 条的实作层回报

## 9. 对当前实现的约束

这一层虽然在 MVP 之后，但下面几条现在就得守住：

1. **设备与收容单元共用底层结构**（基线 4.5 已写）。第 5 节的"越狱 = 失能 → 修复"直接依赖它。
2. **危险等级已经是 attribute**（见 `docs/dev/authoring-contract.md`）。它是 3.1 的"突破后果"坐标，不要拿它当管理难度用。
3. **残余管理难度需要一个独立的作者字段。**它**不能**是 attribute——attribute 是封闭的 13 个且已经花完，而且只是标签、不带值。存放方式见 authoring-contract，待定。
4. **NPC 必须是有身份的个体单位**，不是数量。SP 的"目睹 NPC 死亡"、控制部召回的"非建筑 npc 单位"、中央本部的补充速率，都已经假设了这一点。
5. **不要假设"只有一种游戏模式"**（7.8）。核心抑制是 lobby 属性上的分支，不是另一张图。目前代码里没有任何地方做了这个假设，趁还没有的时候记下来。
