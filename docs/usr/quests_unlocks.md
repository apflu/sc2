# 任务与解锁

永久奖励仅在完成任务后的下一局游戏起生效，见各部门的“被动能力”栏。

## 控制部

解锁：默认解锁

1. 建立一个正常运转的异想体收容单元 并 升级任意房间或走廊的防御设施
2. 对异想体完成4次工作且结果为优
3. 妥善处理3轮融毁
4. [挑战] 完成一次 **黄昏** 考验

核心抑制：工作指令随机在融毁等级提高时调换，NPC会偶尔自行部署到其他房间。

## 情报部

解锁：默认解锁

1. 完成3次异想体工作
2. 对一个至少Zayin等级的异想体的观察等级达到3
3. 将本部门所有升级提高至2级
4. (解锁:)[挑战] 对一个至少WAW等级的异想体的观察等级达到4（完全解锁）

核心抑制：海量正确但无用的信息在游戏过程中遮盖画面。

## 培训部

解锁：默认解锁

1. 提升2名员工的等级
2. 使一名员工的等级达到4以上
3. 镇压（=击杀）4个不同的异想体 - 队友的进度也计算在内。
4. (解锁:控制部3, 中央本部3) [挑战] 员工全部为5级时完成一场游戏

注：属性与等级的关系如下。默认状态下，员工单项属性的上限为99；与原作不同，员工的属性提升在工作完成后立刻发生。
I - <30 - II> - <45 - III> - <65- IV> - <85- V> - <100 - EX>
注2：属性等级总和与员工等级的关系如下。
I - <6 - II> - <9 - III> - <12 - IV> - <16 - V>
注3：镇压是对于突破收容的异想体进行击杀的代名词。由于异想体总是会在收容单元内无限复活，使用击杀不太准确，而只使用镇压又会对玩家造成费解。

核心抑制：员工的属性随着融毁等级的升高而降低。
