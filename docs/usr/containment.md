# 收容单元

## 构成

收容单元拥有一个大门作为唯一出入口，一个可交互、可选中的控制面板作为选择异想体的媒介，以及被npc员工交互（短暂读条的placeholder技能）以传送进收容单元进行工作。常规状态下，收容单元是空的、或容纳一个异想体。

目前而言，我们直接将npc员工放入发呆即可，便当做是在进行工作，在结束后传送出来。

在收容单元中的异想体是无敌的（不可被攻击），且不会做任何事情。机制另有描述的除外。

被从外部破坏（一般因为虫潮或考验）时，大门将会降下，并将其Qliphoth Counter设为0。部分异想体的计数器为X（不适用）；而剩余的异想体在counter为0时几乎必然发生某件坏事。

而在这些异想体当中，出逃（突破收容）则是会发生的最坏的事。

当因管理不善或特殊机制、异想体“决定”出逃时，假如收容单元大门的耐久度未归零时则会攻击大门，直到其降下。这一机制无法被修理阻拦，只能被短暂拖延。额外的，大门会受到特殊Behavior的影响、根据异想体等级逐渐受到越来越高的dot伤害。

当异想体处于“决定出逃”状态且大门降下后，异想体则正式被标注为出逃状态，解除无敌。

此外，并非每个异想体在大门降下时都会做什么。当不会出逃的异想体的大门损坏时，负面后果仅为无法对该异想体进行工作。另外，即使大门降下，玩家、虫潮或员工也无法进入收容单元。

当突破收容的异想体被镇压时，将会在一定延迟后被传送回其收容单元，并恢复到初始行为和状态，Qliphoth Counter恢复到其默认值。大门将被立刻恢复到满生命值并升起。
