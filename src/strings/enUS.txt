# Player-facing text.
#
# Every string a PLAYER can see lives here and is referenced from Galaxy by key,
# never written inline. Inline English is a translation that has already been
# lost: it cannot be found, cannot be handed to anybody, and the day a second
# locale is wanted it turns into a hunt through twenty-six modules.
#
# Debug output is deliberately NOT here. -quest, -fort and the F12 tips are
# developer text; localising them would be work spent so that a translator can
# render a message only I will ever read.
#
# Format is GameStrings.txt's own: Key=Value, one per line, no spaces around the
# equals sign. <n/> is a line break. tools/gen_strings.py merges these into
# LobotomyShiphold.SC2Map/enUS.SC2Data/LocalizedData/GameStrings.txt, replacing
# the whole Lob/ namespace and touching nothing else in that file.
#
#   this file        the enUS source, owned by the repo
#   other locales    <locale>.SC2Data/LocalizedData/GameStrings.txt, owned by
#                    the editor's Text Editor and never written by the build
#
# The build fails if Galaxy references a Lob/ key that is not here, so a typo is
# a build error instead of a blank line in the objectives panel.

# --- Task titles -------------------------------------------------------------
# Title Case, imperative, short. That is Blizzard's own convention for an
# objective -- "Destroy the Protoss Structures", "Gather 5000 Minerals",
# "The Laser Drill Must Survive" -- and it is what makes a column of them read
# as a list of orders rather than a paragraph. A condition that has to hold
# rather than be done is phrased as a statement, the way theirs are.
#
# The progress counter is appended by the code in its own colour, so leave it
# out of the title. Blizzard adds a unit word inside the parens ("(2/3 Rounds)")
# when the title does not name the thing being counted; ours all do, so it would
# be redundancy dressed as polish.
